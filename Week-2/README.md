# Week 2

## HR Employee Attrition Analysis

This folder contains Week 2 internship work centered on analyzing HR attrition data.

### Files

- `analysis.ipynb` - Jupyter notebook with data exploration, visualization, and modeling.
- `WA_Fn-UseC_-HR-Employee-Attrition.csv` - dataset used for the analysis.
- `Charts/` - directory containing charts and visual output from the analysis.

### Notes

- Start with `analysis.ipynb` to follow the end-to-end workflow.
- Use the notebook to explore dataset features, examine attrition trends, and evaluate model performance.
- Generated charts are saved in the `Charts/` folder for reference.
